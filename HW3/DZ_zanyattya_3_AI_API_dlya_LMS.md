## Крок 1. Ключі та безпека

Отримати ключі **мінімум двох** провайдерів. Рекомендую Google (безкоштовний тариф) + будь-який другий.

Далі — обов'язково:

- створити `.env` з ключами;
- додати `.env` у `.gitignore` **до першого коміту**;
- виставити hard limit у білінгу платного провайдера (для Google — просто не вмикати платний тариф);
- перевірити, що ключ читається через `os.environ`, і надрукувати **тільки останні 4 символи**.

## Крок 2. Перший виклик

Зробити один робочий виклик до кожного провайдера і надрукувати три речі: текст відповіді, `stop_reason` / `finish_reason` і кількість токенів входу та виходу.

Якщо тут щось не працює — далі йти немає сенсу. Найчастіші причини: не перезапущений процес після зміни `.env`, забутий `max_tokens` у Anthropic, `system` покладений усередину `messages`.

## Крок 3. Функція llm()

Написати одну функцію з єдиним контрактом і двома гілками всередині:

```
def llm(prompt: str, system: str = "", provider: str = "google") -> dict:
    """
    Повертає словник:
    {
      "text": "...",          # відповідь моделі
      "in_tokens": 412,
      "out_tokens": 87,
      "stop_reason": "end_turn",
      "seconds": 1.8,
      "cost_usd": 0.00042
    }
    """
```

Вимоги:

- ключ береться з `.env`, у коді ключа немає;
- `temperature=0` (або еквівалент), щоб результат був відтворюваним;
- `max_tokens` виставлений під реальну потребу задачі;
- підрахунок токенів і вартості — всередині функції, один раз для всіх провайдерів.

---

## Крок 4. Retry

Додати повтор із експоненційним backoff: 1 → 2 → 4 → 8 секунд, максимум 5 спроб. Після останньої невдалої спроби — чесно падати з помилкою, а не повертати `None`.

**Довести, що це працює:** підставити навмисно невірний ключ, запустити, показати в консолі спроби повтору і фінальну помилку. Скріншот консолі — у звіт.

---

## Крок 5. Прогін тестсету

Взяти **той самий тестсет із 5 входів**, який ви робили в ДЗ заняття 2, і той самий промпт-переможець (v2 з шаблоном на 6 блоків).

Прогнати всі 5 входів через `llm()` на **двох провайдерах** — це 10 викликів. Формат виводу залишити JSON: відповідь має парситись у Python, а не читатись очима.

Вартість рахуємо за формулою:

```
cost = (in_tokens * price_in + out_tokens * price_out) / 1_000_000
```

Ціни `price_in` / `price_out` беремо з офіційної сторінки прайсу провайдера — і вказуємо у звіті, звідки.

## Типові помилки, на яких втрачають час

- Змінили `.env`, але не перезапустили процес — ключ старий
- Забули `max_tokens` у Anthropic → помилка 400
- Поклали `system` у `messages` у Anthropic → помилка 400
- Скопіювали історію з OpenAI у Google, не змінивши роль `assistant` на `model`
- Отримали 429 на безкоштовному тарифі, бо запустили 10 викликів у циклі без пауз — додайте затримку між запитами
- Відповідь обрізана посеред JSON, а причина не в промпті: подивіться `stop_reason` — там `max_tokens`
